Glossary

Welcome to the glossary for Module 2 (Exploratory Data Analysis). Each entry gives the definition of a key term, the sources used for that definition, and three examples drawn from a variety of fields to show the term in action. The terms are listed alphabetically.

Many entries show the R code used to compute or draw the term. These snippets assume a numeric vector x (for example, x <- c(12, 15, 18, 21, 26)), a second numeric vector y, and a categorical vector g (for example, g <- c("Low", "Medium", "High", "Low", "Medium")). The R Reference section at the end of this glossary explains the R used throughout the module: reading a dataset, the tidyverse pipe, and drawing plots with ggplot2.

Categorical Variable

Definition: A categorical (qualitative) variable records which group, category, or label each observation belongs to; the values are names rather than measured amounts. Arithmetic such as addition or averaging does not make sense for categorical data.

Source: Introductory Statistics 2e, p. 38; R for Data Science (2e), ch. 1 “Data visualization”, §1.4.1 “A categorical variable”; Hands-On Programming with R, ch. 5 “R Objects”, §5.1.3 “Characters”

Example 1: Material phase (austenite, ferrite, or martensite) is a categorical variable because each steel specimen is assigned one of three microstructural labels.

Example 2: Blood type (A, B, AB, or O) is a categorical variable naming the blood group of each donor.

Example 3: Rock type (igneous, sedimentary, or metamorphic) is a categorical variable naming the geological origin of each site.

Central Tendency

Definition: Central tendency (centrality) refers to a single value that represents the center, or typical value, of a distribution. The most common measures of central tendency are the mean, the median, and the mode; the appropriate measure depends on the shape of the distribution and the type of variable.

Source: Introductory Statistics 2e, p. 77; R for Data Science (2e), ch. 13 “Numbers”, §13.6.1 “Center”

Example 1: A concrete testing lab summarizes concrete slump measurements with the mean because the distribution is approximately symmetric.

concrete_slump_mm <- c(75.9, 76.4, 82.1, 83.3, 79.3, 80.5, 80.6, 79.6, 81.9, 78.7,
                       78.7, 77.3, 83.2, 79.3, 79.4, 84.7, 77.9, 76.9, 80.7, 75.8,
                       78.8, 80.4, 82.7, 75.2, 80.2, 78.2, 81.8, 81.6)
mean(concrete_slump_mm)
## [1] 79.68214
median(concrete_slump_mm)
## [1] 79.5

Because the distribution is approximately symmetric, the mean and median are close together.

Continuous Variable

Definition: A continuous variable is a quantitative variable that can take any value within a range; between any two possible values there are infinitely many other possible values, and measurements are limited only by the precision of the measuring instrument.

Source: Introductory Statistics 2e, p. 56; R for Data Science (2e), ch. 1 “Data visualization”, §1.4.2 “A numerical variable”; Hands-On Programming with R, ch. 5 “R Objects”, §5.1.1 “Doubles”

Example 1: The width of the widest crack in a bridge deck is a continuous variable because it can take any value within a range of millimeters.

The measurements take many fractional values, limited only by the precision of the gauge.

Example 2: Server response time in milliseconds is a continuous variable because it can take any fractional value.

Nearly every observation is a different fractional value, so the variable is not restricted to a fixed set of steps.

Example 3: The mass of a product in kilograms is a continuous variable because it can take any value within a range.

The values differ by small fractional amounts rather than jumping between whole units.

Correlation

Definition: The correlation coefficient, denoted r, measures the strength and direction of the linear relationship between two quantitative variables.

$$r = \frac{1}{n-1}\sum \left(\frac{x_i - \bar{x}}{s_x}\right)\left(\frac{y_i - \bar{y}}{s_y}\right)$$ Two variables have a linear relationship when their points in a scatterplot tend to fall along a straight line, so a change of one unit in x is associated with a roughly constant change in y. The value of r always lies between −1 and 1: the sign tells the direction (positive when the variables tend to increase together, negative when they move in opposite directions), and the magnitude tells the strength, which describes how tightly the points cluster around a line: weak (points widely scattered), moderate (a clear but loose trend), or strong (points tightly clustered), with values near ±1 indicating a strong linear relationship and values near 0 a weak one. A value near 0 indicates no linear relationship, not necessarily no relationship at all: the points may follow a curve (a nonlinear relationship) that the correlation coefficient does not describe. Correlation measures association, not causation.

Source: Introductory Statistics 2e, p. 642; R for Data Science (2e), ch. 10 “Exploratory data analysis”, §10.5.3 “Two numerical variables”

Example 1: Applied load and deflection of steel specimens show a strong positive linear relationship: as the load increases, the deflection increases roughly in a straight line.

Discrete Variable

Definition: A discrete variable is a quantitative variable that takes only certain separate values, usually whole numbers that come from counting; between two possible values there are no other possible values.

Source: Introductory Statistics 2e, p. 56; R for Data Science (2e), ch. 1 “Data visualization”, §1.4.2 “A numerical variable”; Hands-On Programming with R, ch. 5 “R Objects”, §5.1.2 “Integers”

Example 1: The number of cracks detected in a bridge deck is a discrete variable because you count whole cracks.

Only whole numbers appear; there is no such thing as 2.5 cracks.

Example 2: The number of failed login attempts in an hour is a discrete variable because it comes from counting attempts.

Example 3: The number of items in a customer’s cart is a discrete variable because you count items one at a time.

Interquartile Range (IQR)

Definition: The interquartile range (IQR) is the distance between the first quartile (Q1) and the third quartile (Q3), so it measures the spread of the middle 50% of the data.

$$\text{IQR} = Q_3 - Q_1$$ Because it ignores the extreme values, it is the preferred measure of variability when the distribution is skewed or has outliers.

Source: Mathematical Statistics with Applications in R, p. 20 ; Introductory Statistics 2e, p. 99; R for Data Science (2e), ch. 13 “Numbers”, §13.6.3 “Spread”

Example 1: The IQR of battery lifetimes is 33 hours, meaning the middle half of the batteries fall within a 33-hour span.

                            52.8, 61.7, 74.3, 92.5, 138.4, 209.8)

## [1] 33
quantile(battery_lifetime_hours, probs = c(0.25, 0.75))
##  25%  75% 
## 12.5 45.5

Mean

Definition: The mean (arithmetic average) of a dataset is the sum of all values divided by the number of values.

$$\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$$ It is the appropriate measure of centrality when the distribution is approximately symmetric, because it uses every observation; it can be pulled away from the center by skewness or outliers.

Source: Mathematical Statistics with Applications in R, p. 15 ; Introductory Statistics 2e, p. 77; R for Data Science (2e), ch. 13 “Numbers”, §13.6.1 “Center”

Definition: The median is the middle value of a dataset when the values are arranged in order; half of the observations fall below it and half above.

Outlier

Definition: An outlier is an observation that lies unusually far from the rest of the data and does not fit the general pattern. Using the 1.5 × IQR rule, a value is an outlier if it falls below Q1 − 1.5 × IQR or above Q3 + 1.5 × IQR, where

$$Q_1 - 1.5 \times \text{IQR} \quad \text{or} \quad Q_3 + 1.5 \times \text{IQR}$$ , where Q1 and Q3 are the first and third quartiles and IQR is their difference.

Source: Mathematical Statistics with Applications in R, p. 15 ; Introductory Statistics 2e, p. 79; R for Data Science (2e), ch. 10 “Exploratory data analysis”, §10.3.2 “Unusual values”

Example 1: Two furnace temperature readings of 165.8°C and 169.1°C lie above the upper fence, so they are outliers among readings clustered near 150°C.

furnace_temp_c <- c(148.2, 149.0, 149.6, 150.1, 150.4, 150.7, 151.0, 151.3,
                    151.8, 152.4, 153.1, 153.9, 154.8, 165.8, 169.1)
Q1 <- quantile(furnace_temp_c, 0.25)
Q3 <- quantile(furnace_temp_c, 0.75)
lower_fence <- Q1 - 1.5 * IQR(furnace_temp_c)
upper_fence <- Q3 + 1.5 * IQR(furnace_temp_c)
furnace_temp_c[furnace_temp_c < lower_fence | furnace_temp_c > upper_fence]
## [1] 165.8 169.1

Skew

Definition: Skew describes the asymmetry of a distribution, determined by which tail stretches out farther. A distribution is right-skewed (positively skewed) when its right tail stretches toward the larger values while the bulk of the observations pile up on the left; a distribution is left-skewed (negatively skewed) when its left tail stretches toward the smaller values while the bulk of the observations pile up on the right; and a distribution is approximately symmetric when the two sides fall away from the center at about the same rate and the mean and median are close together. In a skewed distribution the mean is pulled toward the tail (larger than the median when right-skewed, smaller when left-skewed), so the median is the preferred measure of centrality.

Source: Introductory Statistics 2e, p. 93; R for Data Science (2e), ch. 13 “Numbers”, §13.6.1 “Center”

Standard Deviation

Variance

Definition: The variance (s²) is the average of the squared deviations of the observations from the mean; it measures spread in squared units.

R Reference: Reading and Working with Data in R

The definitions in this glossary show the R code that computes each summary, and the module narratives show that code working on a real dataset. This reference collects the pieces of R that appear throughout — reading data, the tidyverse pipe, and the grammar of ggplot2 — with short explanations of what each piece does.

Reading a dataset into R

A data file is usually a CSV: a table of rows (observations) and columns (variables). read.csv() reads it into a data frame, the tidy table R uses for statistics. names() lists the columns, nrow() counts the rows, and \$ pulls out a single column.

# Load the tidyverse (data wrangling) and ggplot2 (plotting) packages
library(dplyr)
library(ggplot2)

# Read a CSV file saved in your working directory
gas <- read.csv("data/gas_prices_states_original.csv")

# List the columns and count the rows
names(gas)
##  [1] "state"                 "region"                "party"                
##  [4] "regular_price"         "midgrade_price"        "premium_price"        
##  [7] "diesel_price"          "gas_tax"               "gas_tax_rank"         
## [10] "diesel_tax"            "diesel_tax_rank"       "refining_capacity_bpd"
## [13] "population"
nrow(gas)
## [1] 51
# Pull out a single column with $
mean(gas$regular_price)
## [1] 4.389814

summary() is a quick all-in-one: for a numeric column it prints the minimum, first quartile, median, mean, third quartile, and maximum.

summary(gas$regular_price)

##   3.722   4.055   4.287   4.390   4.471   6.376

The tidyverse pipe

The pipe %>% takes whatever is on its left and hands it to the function on its right, so a chain of pipes reads like a recipe: take the data, keep these rows, keep these columns, count them. The most common verbs are:

  • filter() keeps the rows that meet a condition
  • select() keeps only the named columns
  • arrange() sorts the rows
  • slice_head() / slice_tail() take the first / last rows
  • mutate() adds a new column
  • count() counts the rows in each group
  • group_by() + summarize() compute a summary within each group
# Keep only cheap states, then count them
gas %>%
  filter(regular_price < 4.00) %>%
  count()
##   n
## 1 9

Drawing plots with ggplot2

A ggplot2 plot is built by adding layers to ggplot(). The first call names the data and maps columns to parts of the plot with aes(); each geom_*() layer draws something. labs() sets titles and axis labels, and theme_minimal() gives a clean look.

# Histogram of a quantitative variable
ggplot(gas, aes(x = regular_price)) +
  geom_histogram(binwidth = 0.2) +
  labs(title = "Regular gas prices") +
  theme_minimal()

The geom_*() layers used in this course are:

  • geom_histogram() — a histogram for one quantitative variable
  • geom_boxplot() — a boxplot for one or more quantitative variables
  • geom_bar() — a bar chart for a categorical variable
  • geom_point() — a scatterplot for two quantitative variables

binwidth in geom_histogram() sets the width of the bins, and fill / color set the fill and outline colors.

A few helpers

  • round(x, digits) rounds a number to the requested number of decimal places (used to find the mode of a rounded variable)
  • min(x) and max(x) give the smallest and largest values (defined under Minimum and Maximum)
  • cor(x, y) measures the strength and direction of a linear relationship (defined under Correlation)
